1. Define the interval scheduling problem precisely: one resource, pairwise-compatible intervals, and maximum cardinality.
Basically, when there is only one resource, it becomes important to ensure that resource it being utilized effeciently. The interval scheduling problem is therefore just determining which intervals to schedule the resource so it is being used the best. This means that intervals, defined by start and end times, cannot overlap in order to be in the best schedule. The end time could be the same as the start time of the next interval, but a start time less than the end time would mean it is not in the solution. In order to be efficient, you need to select the greatest number of intervals rather than ones that last the longest.

2. Explain the greedy strategy and why the implementation sorts by finish time before scanning.
The greedy strategy focuses on making decisions based on only what you can see at the present moment, rather than trying to take in all of the potential solutions to pick the best one. This implementation sorts by the finish time to make sure that the greedy startegy is going to pick solutions in the correct order. Finishing time is what dictates what intervals to select next, so ensuring that sort is in place will ensure the greedy strategy will pick the next best time.

This interval scheduling is useful when there is one resource and many things requiring that resource's attention. The amount that can be done is restricted to the single resource, so the resource cannot overlap tasks and therefore needs to be scheduled to take on the most non-overlapping tasks.
